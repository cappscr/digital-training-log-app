# Intent: sidebar nav

## Problem

The app currently uses an horizontal rail across the top of the page for primary navigation for both pre-authentication pages and post-authentication application pages.

## Proposed Outcome

Within the authenticated portion of the app, the primary navigation moves from the top nav bar to a collapsible sidebar following the pattern laid out in the [shadcn blocks documentation](https://ui.shadcn.com/blocks/sidebar#sidebar-07).
