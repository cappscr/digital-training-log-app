## Conventions

- Organized as a monorepo with four top-level directories: `frontend`, `backend`, `intent`, and `spec`.
- Almost all new changes should get an `<slug>/intent.md` file describing the intent.
- `<slug>/spec.md` describes the _current state_ of the design and implementation details. Changes to the design or implementation should update these files.
- Never commit `.env` files
